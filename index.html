Política de Privacidad

Última actualización: Agosto 2026

1. Información que recopilamos

Esta aplicación no almacena ni comparte datos personales identificables de terceros. Únicamente procesamos tokens de acceso y credenciales mediante las APIs de TikTok y Meta para la publicación automatizada de contenido multimedia en la cuenta autorizada.

2. Uso de la información

Los datos procesados se utilizan exclusivamente para:

  • Autenticar la conexión con las plataformas de redes sociales.
  • Subir y programar videos en la cuenta vinculada del usuario.

3. Seguridad

Las credenciales de las APIs se manejan mediante variables de entorno seguras y no son accesibles para terceros.

4. Contacto

Para dudas sobre esta política de privacidad, puedes contactarnos en: tu-correo@email.com
